# 예제용 양식

## startup_plan_form.hwp

`fill_form.py` 가 변환해서 채우는 **빈 양식**이다. 내용은 들어 있지 않고 라벨과
작성 안내문만 있다.

| 항목 | 내용 |
|---|---|
| 원본 파일명 | `양식. 사업계획서(Business Plan, hwp)_2026 학생 창업유망팀 300+(2026 Promising Student Startup Team 300+).hwp` |
| 성격 | 정부 지원사업 배포 서식 (빈 양식) |
| 형식 | 구식 HWP 5.x 바이너리 → 예제가 HWPX 로 변환해서 사용 |

파일명이 너무 길어 저장소에서는 `startup_plan_form.hwp` 로 줄였다. 내용은 그대로다.

## 이 양식으로 확인되는 것

- **구식 `.hwp` 변환** — `[hwp]` 부가 설치가 있어야 동작한다
- **라벨로 칸 찾기** — 표 인덱스가 아니라 `find_label(..., direction="below")` 로
  찾으므로, 양식이 개정되어 표 순서가 바뀌어도 라벨만 같으면 계속 동작한다
- **안내문 색 함정** — 안내문이 파란색(`#0000FF`)이라 그대로 채우면 본문이
  파랗게 나온다. `color="#000000"` 으로 되돌린다 (`references/gotchas.md` 참고)

## 배포 조건

공공기관이 배포한 제출용 서식이다. 재배포 조건은 배포 기관의 공지를 따른다.
저장소에 포함한 것은 예제 실행을 위해서이며, 내용이 채워지지 않은 빈 양식이다.
문제가 되면 이 파일만 제거해도 나머지 예제 두 개는 그대로 동작한다.
