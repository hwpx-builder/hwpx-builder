# 예제용 데이터

## penguins.csv

남극 Palmer Archipelago 3개 섬에서 관측한 펭귄 344마리의 형태 측정 데이터.
`build_research_report.py` 가 이 파일을 분석해 보고서를 만든다.

| 항목 | 내용 |
|---|---|
| 출처 | [palmerpenguins](https://allisonhorst.github.io/palmerpenguins/) |
| 수집 | Dr. Kristen Gorman, Palmer Station LTER |
| 라이선스 | **CC0** (퍼블릭 도메인 헌정) |
| 인용 | Horst AM, Hill AP, Gorman KB (2020). palmerpenguins: Palmer Archipelago (Antarctica) penguin data. R package version 0.1.0. doi:10.5281/zenodo.3960218 |

iris 데이터셋을 대체할 **교육·예제용**으로 공개된 것이라, 이런 용도에 쓰라고
만들어진 자료다. 그래서 예제 데이터로 골랐다.
